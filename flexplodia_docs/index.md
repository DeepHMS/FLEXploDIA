# FLEXploDIA Tutorials

FLEXploDIA explores, edits and visualizes spectral libraries, and helps design and validate
dia-PASEF methods. Each tab has its own tutorial:

| Tab | What it is for |
|---|---|
| [Library Explorer](library-explorer.md) | Statistics and 11 plots for a whole library or one protein |
| [Library Editor](library-editor.md) | Convert, annotate, extract and merge libraries |
| [Prot./Pep. Cloud Viz.](cloud-viz.md) | Peptidoforms of a protein in the ion cloud, with fragment fingerprints |
| [Method Developer](method-developer.md) | Design Diagonal-PASEF and Slice-PASEF methods |
| [PASEF Validator](pasef-validator.md) | Compare a DDA library with the DIA library a method produced |

!!! tip "Online or desktop?"
    The [online version](https://deepbiswas-flexplodia.hf.space) takes libraries up to 50 MB.
    For larger libraries, download the desktop version from
    [GitHub](https://github.com/DeepHMS/FLEXploDIA).
